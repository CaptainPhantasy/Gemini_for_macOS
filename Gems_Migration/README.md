# Gems Migration Staging Area

Place the instructions and custom prompts for your existing Google Gems here.
Since there is no direct export API from the Google web interface, please follow this process:

1. Create a new text file for each Gem (e.g., `Coding_Assistant.md`).
2. Copy and paste the custom instructions from the web UI into the file.
3. Once pasted, tell me, and I will ingest them and convert them into local agent profiles or prompt templates.
